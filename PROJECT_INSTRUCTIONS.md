# Instructions permanentes pour l'assistant

À chaque demande liée au site pédagogique CM2 :

1. Utiliser le dépôt GitHub canonique `JuliaKADINO/learnCM2`.
2. Modifier en priorité la branche `main` de ce dépôt au lieu de créer un nouveau site ou un nouveau lien.
3. Considérer l'adresse GitHub Pages `https://juliakadino.github.io/learnCM2/` comme l'adresse publique de référence dès que GitHub Pages est activé.
4. Ne jamais afficher de prénom d'élève dans le site, les exercices, le code ou les bilans. Employer des formulations génériques comme « une élève », « un enfant », « une amie ». Michael Jackson peut être nommé.
5. Préserver autant que possible la compatibilité de la sauvegarde locale et la progression existante lors des mises à jour.
6. Conserver les exigences pédagogiques du projet : QCM à choix unique, trois réponses, indice à la demande, réponse expliquée, abandon possible sans blocage, bilan parent et reprise exacte sur le même appareil.
7. Avant une nouvelle semaine, consulter les résultats précédents disponibles et renforcer les notions fragiles sans répétitions inutiles.
