# Learning Machine CM2

Ce dépôt est le site public canonique du projet pédagogique CM2.

## Site public

Adresse GitHub Pages attendue :
`https://juliakadino.github.io/learnCM2/`

Le site doit toujours être mis à jour dans **ce même dépôt**, branche `main`, afin de conserver la même adresse publique d'une semaine à l'autre.

## Règles permanentes

- Ne jamais afficher de prénom d'élève dans le site, le code, les exercices ou les bilans.
- Michael Jackson peut être nommé ; les autres prénoms doivent être remplacés par « une élève », « un enfant », « une amie », etc.
- Conserver les semaines précédentes et leur progression quand une nouvelle semaine est ajoutée.
- QCM à choix unique uniquement, trois réponses possibles par question.
- Indice uniquement à la demande.
- Bouton « Voir la réponse » avec explication.
- Une question peut être passée ou abandonnée sans bloquer la série.
- Sauvegarder localement la réponse choisie, les tentatives, indices, réponses révélées, abandons, position exacte et séries terminées.
- Maintenir les sections « Préparer une évaluation », « Réviser les cours de demain » et « Bilan parent ».
- Utiliser le dépôt GitHub `JuliaKADINO/learnCM2` comme source principale du site ; ne pas créer un nouveau site final à une autre adresse sauf demande explicite.

## Déploiement

GitHub Pages doit être activé depuis la branche `main`, dossier `/ (root)`. Une fois activé, les mises à jour de `index.html`, `style.css` et des autres fichiers du dépôt sont publiées à la même adresse.
